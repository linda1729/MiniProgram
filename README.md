# 🧪 实验概览

## **🧪 实验 1：微信小程序基础与界面搭建**

该实验主要完成：

- 小程序项目创建、目录结构理解
- 学习 WXML / WXSS / JS 三段式开发
- 简单界面设计与组件使用

这是进入微信小程序开发的“基础篇”。

## **🧪 实验 2：小程序组件练习 + 接口调用**

实验 2 内容包括：

- 使用按钮、输入框、列表等组件

## **🧪 实验 3：小程序云开发 + 文本搜索功能**

实验目标：实现“垃圾分类文本搜索”功能。

实验涉及：

- 开启云开发（env 配置）
- 创建云数据库集合 `trash`、`type`
- 配置 API Key + Secret Key（百度智能云接口）
- 编写云函数，实现：
  - Text → 分类名查询
  - 在前端触发搜索
- 部署 cloudfunctions
- 在小程序页面实时展示查询结果

实验重点在于：**云函数调用 + 文本搜索业务逻辑 + 接口调试**。

## **🧪 实验 6：完整的推箱子游戏（微信小程序）**

### **功能模块**

#### ✔ 首页

- 展示四个游戏关卡（动态渲染）
- 每个关卡对应图片（`level01.png` 等）
- 点击后跳转到游戏页面携带参数：`level=n`

#### ✔ 游戏界面

- Canvas 绘图
- 地图层（墙、地面、终点）
- 箱子层
- 人物层
- 方向键控制（↑ ↓ ← →）
- 游戏胜利判定
- 重新开始按钮

### **关键技术点**

- utils/data.js：关卡 1～4 的 8×8 地图矩阵
- initMap：初始化地图 + 人物位置
- drawCanvas：逐格绘制墙、地面、箱子、目标点、人物
- 碰撞检测逻辑（箱子前方是否能推动）
- isWin：检查所有箱子是否都到达目标点
- checkWin：胜利弹窗

这个实验完整体现了小程序的：

- Canvas 绘图
- 多层数据状态管理
- 事件交互
- 页面跳转
- 动态渲染

# ▶️ 如何运行项目

## **运行微信小程序（实验 1–4、实验 6）**

1. 打开微信开发者工具
2. 选择导入项目
3. 选择 `MiniProgram/miniprogram` 目录
4. **确保已设置云开发环境（若涉及实验 3）**
5. 点击预览 / 编译即可

推箱子（实验 6）如果要直接调试第 1 关，可使用“添加编译模式”并设置参数：

```
level=0
```

------

## **运行 HarmonyOS 应用（实验 5）**

1. 打开 DevEco Studio
2. 选择 `entry` 工程路径
3. 运行模拟器或使用真机
4. 点击首页按钮可跳转到第二页，点击返回可回到首页
